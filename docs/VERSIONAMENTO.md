# Política de versões

O projeto segue o Versionamento Semântico (MAJOR.MINOR.PATCH).

- `v1.0.0-alpha`: primeira versão de teste, com funcionalidades básicas
- `v1.0.0-beta`: funcionalidades completas, em fase de testes
- `v1.0.0`: primeira versão estável

## Como criar uma release

1. Atualizar o CHANGELOG.md
2. Abrir um PR da branch `release/x.y.z` para a `main`
3. Após o merge, criar a tag e a release no GitHub
